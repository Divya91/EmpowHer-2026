# ✈️ Flight Booking System

A modern **Flight Booking System** built with **Angular 21** that allows users to search for flights, view available options, and manage flight bookings through an intuitive and responsive interface.

---

## 🚀 Tech Stack

- **Angular 21.2.7**
- TypeScript
- HTML5
- CSS3
- Angular CLI
- Vitest (Unit Testing)

---

## 📋 Prerequisites

Before running the project, make sure the following are installed:

- Node.js (Latest LTS version recommended)
- npm
- Angular CLI

Install Angular CLI globally if you haven't already:

```bash
npm install -g @angular/cli
```

---

## ⚙️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd FlightBookingSystem
```

Install the dependencies:

```bash
npm install
```

---

## ▶️ Running the Application

Start the development server:

```bash
ng serve
```

Open your browser and visit:

```
http://localhost:4200
```

The application will automatically reload whenever changes are made to the source code.

---

## 🏗️ Build the Project

Create a production-ready build:

```bash
ng build
```

The compiled files will be generated inside the **dist/** directory.

---

## 🧩 Generate Components

Angular CLI makes it easy to generate components, services, directives, and more.

Generate a component:

```bash
ng generate component component-name
```

Generate other Angular resources:

```bash
ng generate --help
```

## 🧪 Testing

### Unit Tests

Run unit tests using Vitest:

```bash
ng test
```

### End-to-End Testing

Run end-to-end tests:

```bash
ng e2e
```

> Angular does not include an e2e testing framework by default. You can integrate tools such as Cypress or Playwright based on your project requirements.
